**_termusic_ - минималистичный легкий музыкальный плеер для терминала насисаный на C**

> этот проект создовался как эксперемент и не стоит расмативать его как что то серезное и стоющее внимания 

### упровление и горячие клавиши:
- **q**               - выход из программы 
- **стрелки "↑" "↓"** - перемещение курсора в верх/вниз
- **Enter "↵"**       - запуск проигрывания выбраной конмозиции  
- **пробел**          - пауза/продолжение вопроизведения композиции
- **+** и **-**       - увеличение и уменьшение громкости
- **→** и **←**       - перематывает музыку ну десять секунд вперед/назад
